# Instituto REZENDE - Landing Page

Bem-vindo à landing page profissional do **Instituto REZENDE - Reabilitação Infantil Especializada**!

## 🎯 Sobre o Projeto

Este é um website moderno e responsivo criado com HTML, CSS e JavaScript puro, desenvolvido para apresentar os serviços especializados de reabilitação infantil oferecidos pelo Instituto REZENDE em Paraupebas, PA.

## ✨ Características

✅ **Design Responsivo** - Funciona perfeitamente em dispositivos móveis, tablets e desktops
✅ **Navegação Suave** - Scroll smooth e links de navegação intuitivos
✅ **Animações** - Efeitos visuais elegantes e suavizados
✅ **Cores Profissionais** - Paleta de cores cuidadosamente escolhida (roxo, dourado, verde)
✅ **Acessibilidade** - Construído com boas práticas de acessibilidade web
✅ **Performance** - Otimizado para carregamento rápido
✅ **SEO-Friendly** - Estrutura semântica HTML para melhor indexação

## 🚀 Como Usar

### Opção 1: Abrir Localmente
1. Clone este repositório ou baixe os arquivos
2. Abra o arquivo `index.html` em seu navegador
3. Pronto! A página carregará

### Opção 2: Usar com GitHub Pages
1. Vá para **Settings** do repositório
2. Vá para **Pages** (no menu lateral)
3. Selecione **main** como branch
4. Clique em **Save**
5. Sua página estará disponível em: `https://andersonrafael1.github.io/instituto-rezende/`

## 🛠️ Customizações Recomendadas

### Adicionar Links Reais
```html
<!-- No HTML, substitua URLs placeholder -->
<a href="seu-link-aqui">Link</a>
```

### Conectar com Sistema de Agendamento
```javascript
// No script.js, atualize a função:
function showScheduleModal() {
    // Integre com seu sistema de agendamento
    window.location.href = 'seu-link-de-agendamento';
}
```

### Adicionar Chat Real
```javascript
// Integre com Zendesk, Intercom, ou seu provedor preferido
function openChat() {
    // Código do seu sistema de chat
}
```

### Personalizar Imagens
- Substitua as imagens placeholder no `index.html`
- Use URLs reais ou imagens locais
- Mantenha proporções 1:1 ou 4:3 para melhor resultado

## 🎓 Como Expandir

### Adicionar Novas Seções
1. Crie uma nova `<section>` no HTML com um `id`
2. Adicione links de navegação na navbar
3. Estilize usando as variáveis CSS já definidas

### Exemplo: Nova Seção
```html
<section id="contato" class="contato">
    <div class="container">
        <!-- Seu conteúdo -->
    </div>
</section>
```

## 🐛 Troubleshooting

### Página não carrega estilos
- Certifique-se de que `styles.css` está no mesmo diretório
- Limpe o cache do navegador (Ctrl+Shift+Delete)

### Animações lentas
- Atualize seu navegador
- Desabilite extensões que podem interferir

### Links não funcionam
- Verifique se os `id`s das seções correspondem aos `href`s
